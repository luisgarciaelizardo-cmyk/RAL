# RAL – Grúas y Maniobras Industriales

Página web de GS RAL Proveedores Industriales (Saltillo, Coahuila).

- `index.html` – página principal
- `styles.css` – estilos
- `assets/logo.jpg` – logo del negocio 

Para verla, abre `index.html` en el navegador. Se puede publicar gratis con GitHub Pages
(Settings → Pages → Deploy from branch).
